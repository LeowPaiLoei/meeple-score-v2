# 🏰 Meeple Score V2 — Premium Medieval Edition

An experimental visual redesign of **Meeple Score**, built as a separate repository so the stable version remains untouched.

## Direction

**Premium Medieval Board Game**

- Parchment, carved wood, antique gold and meadow textures
- Original medieval-inspired decorations rather than official Carcassonne artwork
- Compact score dashboard for 2–6 players
- Multi-player score events
- City, Road, Church / Flower, Farmer, and Goods scoring
- Chicken, Cloth, and Rice goods
- Per-player recent score history
- Live pseudo-3D 50-space score track with lap indicators
- Desktop-specific large-screen polish with expanded layout and track
- Tied-score competition ranking (e.g. 1, 1, 3)
- Decorative medieval score-action plaque and enriched background scenery
- Offline-capable PWA for iPad

## Safety

The stable app remains in the original `meeple-score` repository. This V2 repository is used for visual experiments and larger UI changes.
